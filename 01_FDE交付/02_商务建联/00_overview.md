# 02 商务建联

上游：[交付流程与阶段](/kb/FDE方法论与产品/01_FDE交付/00_交付流程与阶段.md)。

## 本段方法论

### 建联方法

1. **接收已填好的客户资料清单**：PM 核对清单中的一次需求交接依据、已知事实与待核实项，带着缺口约客户对接人电话或线上沟通。我方提问、我方记录，按客户情况挑选问题；部门问到负责人，生意问到客户和订单，流程问到可写出的具体步骤。
2. **确认二次需求、约进场时间**：在二次需求表核对组织结构、数据环境、初步业务流、初步生产线及具体案例，区分事实和待核实项；确认进场日期、角色、观察场景和资料准备。
3. **生成客户版调研手册**：以本夹通用现场调研手册为底，按行业、组织、业务及场景选部门题库和场景卡，删去不适用问题，保留现场核实项。已核实信息及其来源随客户版手册携带。
4. **取得客户确认**：用客户版现场调研计划列日程、地点、人员、资料、观察范围及许可事项，记录客户回复并固定安排。将二次需求表、客户版调研手册和确认的调研安排同版交现场调研负责人。

完成时三件材料均有来源、版本、负责人、接手入口；事实与未知项分开。

## 触发物

客户资料清单（含一次需求交接依据）。

由[第 1 段 商机背景](/kb/FDE方法论与产品/01_FDE交付/01_商机背景/00_overview.md)交接；接手人核对材料版本及缺项。

按需沟通：[C2](/kb/FDE方法论与产品/01_FDE交付/沟通模板/C2.md) · [C3](/kb/FDE方法论与产品/01_FDE交付/沟通模板/C3.md) · [群公告](/kb/FDE方法论与产品/01_FDE交付/沟通模板/群公告.md)。PM 填实际事项、责任人与下次反馈时间，给对应客户或内部责任人；发送前核对版本和接续动作。

## 产出物与去向

二次需求表 ＋ 客户版调研手册 ＋ 确认的调研安排。

交[第 3 段 现场调研](/kb/FDE方法论与产品/01_FDE交付/03_现场调研/00_overview.md)负责人，核对可访问的版本、签收人和未决项。
