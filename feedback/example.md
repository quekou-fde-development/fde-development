# 示例：下载工具包后找不到入口说明

以下为虚构填写示例，不是真实故障，也没有创建实际 Issue。

- **类型**：工具使用问题
- **文件或版本**：`tools/packages/example-tool-0.0.0.zip`（虚构）
- **问题和步骤**：下载并解压后，尝试按 README 找到运行入口；文档所列的示例路径在包中不存在。
- **预期结果**：README 指向包内实际存在的入口，并列出运行前提。
- **公开证据**：可附不含客户资料的目录截图或终端报错。

维护者后续记录示例：由负责该工具的人接手，在修改 PR 中修正文档路径；用新包重新解压并按说明找到入口后，在原 Issue 贴出版本和验证结果，再关闭。
