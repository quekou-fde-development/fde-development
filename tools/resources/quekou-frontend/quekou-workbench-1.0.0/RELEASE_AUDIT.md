# 公司共享版 1.0.0 审查报告

审查日期：2026-09-28。范围：杭州缺口工作台的视觉规范、前端组件、页面配方、客户项目创建、Codex 项目技能和公司共享材料。

## 结论与适用范围

可作为公司统一的前端开发基线，用于制作业务原型和客户工作台前端。原五阶段的工具、规范、素材和日常调用协议已齐备。
它不包含真实业务系统的后台能力，不能因为前端检查通过就直接承诺客户系统“生产上线完成”。每个客户按 docs/上线验收.md 补齐数据、登录、服务端权限、真实保存与运行环境。

本次不是独立第三方安全认证，也不是对未来依赖漏洞、所有浏览器或任意客户改动的保证。

## 审查前发现与处理

| 问题 | 对使用的影响 | 本次处理 |
|---|---|---|
| Vite 6.4.1、PostCSS 8.5.6 存在已知高风险问题 | 开发工具链不能按原版本交付 | 升级 Vite 6.4.3、PostCSS 8.5.28；完整依赖联网检查为 0 项已知漏洞 |
| 检查脚本依赖个人电脑路径 | 同事无法按相同步骤验收 | 本地 Playwright 依赖、可配置浏览器、独立测试服务和临时目录 |
| 缺少公司共享与新项目入口 | 同事需手工复制，易误改母版 | 新目录生成器、独立安装包、Codex 项目技能、版本与完整性检查 |
| SVG 图表在窄屏缩小辅助文字 | 手机阅读困难 | 固定最低图表宽度、内部滚动，实际文字检查至少 13px |
| 趋势负数与无效数值 | 可能出现图形越界或误导 | 支持正负范围；无效值明确提示，不伪装成正常数据 |
| 异步危险操作过早关闭 | 失败时用户误以为成功，可重复提交 | 等待结果、阻止重复请求、失败提示和重试；空确认词不能触发 |
| 加载时可能显示旧进度/摘要 | 把旧信息误当新结果 | 加载期间隐藏相应旧内容 |
| 客户模板首次连接检查失败 | 新建项目无法构建 | 修正日期范围回调，独立目录重新构建通过 |

依赖安全信息来源：npm 官方联网审计返回，原始记录 qa/release/npm-audit.json。
升级前包含 [Vite 公告](https://github.com/vitejs/vite/security/advisories/GHSA-p9ff-h696-f583) 与 [PostCSS 公告](https://github.com/advisories/GHSA-6g55-p6wh-862q) 等；以本次审计的版本范围为准。

## 可交付内容

- 三风格 × 四页面参考图、可编辑色板、第三方依赖和许可证清单。

## 公司接下来怎么用

1. 工具包维护人把此版本放到公司认可的内部共享位置，保留版本号和校验文件。
2. 每位同事打开完整文件夹，在 Codex 跑一次“我的练习工作台”指令，以能打开页面并完成设置演练为通过标准。
3. 每个客户指定业务负责人和技术负责人；根据真实需求修改独立项目，上线清单通过后才用于正式业务。
