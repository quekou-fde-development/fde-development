# 可复用材料

- 缺口标准色板：brand-palette.svg；数值从 design/tokens.json 生成。
- 页面参考：previews/ 下为三种风格的四类页面截图；它们是虚构数据演示，不是客户成果证明。
- 可编辑素材：design/tokens.json、design/style-spec.md、packages/ui 的组件/区块/配方，以及 starter 客户骨架。
- 图标：通过 lucide-react 使用；不重绘缺口 logo，不额外加入 UI 图标库。
- 字体：使用系统字体后备；不需要下载或向同事分发商业字体。
- 依赖资料：dependencies.json、licenses/。

品牌原始依据：《缺口公司VI系统.pdf》v1.0 · 2026.07，第 6 页。原始 PDF 不依赖个人电脑路径，也不是启动必需文件；需完整 VI 时向公司品牌资料负责人获取。
