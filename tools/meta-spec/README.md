# Meta Spec

从通用调研输入和原件出发，分析业务流与系统架构，形成九份交总架构师审核的设计文档。

[阅读 Skill](source/SKILL.md) · [下载 ZIP](meta-spec-10.09.1.zip) · [查看验证说明](source/verification.json)

本版基于已测试的 v14，经夏洛克确认保留当前版本并发布。名称统一为 Meta Spec，执行逻辑和九份参照沿用 v14。安装以 ZIP 为准，解压后的 `meta-spec/` 为安装根；仓库 `source/` 与安装包文件逐项一致。

四个独立案例各生成九份文档，15 项机械断言均通过。业务验收分别为借用案例 11/11、客户案例 12/12、巡检案例 9/13、培训报名案例 16/17。培训案例九份文档内容通过，送审报告缺少审核顺序、退回或暂停的后果及可复制回复；巡检案例有日期字段读权限遗漏，以及禁止输入规则与主管指定负责人冲突的问题。上述问题保留，后续按实际反馈修订。

这些结果尚不能证明跨案例和重复运行的稳定性。真实客户项目、目标宿主安装与平台执行未验收。生成的项目设计仍须总架构师审核。

[九份架构写作参照](../../handbook/architecture-reference/)供人工阅读。Skill 自带同一组 `source/references/design/`；王磊八份原件保留字节，新增第 3 份数据结构参照。
