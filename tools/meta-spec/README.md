# Meta Spec

从通用调研输入和原件出发，分析业务流与系统架构，形成九份交总架构师审核的设计文档。

[阅读 Skill](source/SKILL.md) · [下载候选 ZIP](meta-spec-10.09.zip) · [查看验证说明](source/verification.json)

安装以 ZIP 为准，解压后的 `meta-spec/` 为安装根。仓库 `source/` 保存同一文件集；外层说明和 ZIP 不参与 Skill 的递归校验。运行和产物要求见 Skill，项目设计仍须总架构师审核。

当前为已公开的验证候选。已有证据包括独立 c7 完整试跑、定向修订与独立 c9 复核；最终 c9 尚未重新完成一次独立从零试跑。真实客户项目、安装后宿主运行及总架构师审核待完成，尚未提升为现役 Skill。

[九份架构写作参照](../../handbook/architecture-reference/)供人工阅读与审核。Skill 自带 `source/references/design/`，用于保持安装包自包含；两处九份参照逐文件一致。
