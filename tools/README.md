# 开发工具

实际工具包正在逐包核对后接入。版本、可用状态、依赖和限制集中记录在 [catalog.json](catalog.json)。

计划收齐 Workbench App Development、Meta Skill、Meta Orchestrator、Meta Agent、Meta Architecture Development、前端共享包及手册所需专项工具资料。每包提供 ZIP；适合阅读和使用的 Skill 配套文件同时展开保存。

状态含义：`candidate` 为待审候选；`reference-specification` 为设计规格资料；`published-package` 表示已发布可下载包，实际运行按包内前提执行；`validated-with-conditions` 表示在列明条件下已验证。发布并不自动授予生产可用或总架构师批准状态。
