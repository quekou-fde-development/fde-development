# 架构设计手册（架构师）

[阅读手册10.15.4](architecture-handbook.md) · [全部模板](../02-project-management/templates/README.md)

## 阅读与执行

1. 以现场调研和场景基线梳理业务流，定义问题与产品，说明范围、价值及报价依据。
2. 总架构师进行**方案审核（闸1）**，判断商业可行性。
3. 项目架构师提出技术可行性，团队形成B组九份spec及独立开发计划，总架构师进行**开发审核（闸2）**。
4. 开发审核通过并落实开工条件后，FDE沿[开发手册](../04-development/development-handbook.md)执行开发、测试与发布。

方案与技术材料可以并行准备，审核先方案后开发；技术送审对应已通过的方案版本。PM代表客户核对业务和基线、协调资源并组织正式送审。
