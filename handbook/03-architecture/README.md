## 架构与开发的试行衔接

架构手册覆盖签约后、进场调研到方案送审，产出回答句、场景量表、调研基线和文件组 A。现按以下顺序衔接：

1. **项目架构师形成 A 并过闸 1**：按架构手册完成前半段；文件组 A 的写法可沿用[FDE开发手册](../04-development/development-handbook.md) §2–§3。
2. **FDE 从开发手册 §4 起承接**：基于 A 形成文件组 B 的九份 spec、可行性结论和独立开发计划。
3. **开发手册 §5 的汇总送审按闸 2 执行**：文件组 A 只复核闸 1 之后的改动，具体清单见架构手册 §10。
4. **闸 2 通过后进入开发**：沿开发手册 §6、§13–§14 完成开发、测试、复核、发布及技术交接。

架构手册为试行版，开发手册正文仍为10.09.2；后续正文对齐在试行验证后更新。Meta Spec 当前发布版本及使用条件按[工具说明](../../tools/meta-spec/)执行。
