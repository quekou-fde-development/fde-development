# 开发架构与计划送审邮件

[返回项目管理手册](../../project-management-handbook.md#stage-46) · [全部模板与参考](../README.md)

沿FDE开发手册§5.2的现有格式。填入同一固定commit的材料链接；发送行为由项目经理执行。

```text
主题：【项目编号】【架构送审】【版本】项目简称

项目：项目编号、客户、期数
范围：场景编号与名称
Arcubase：母项目记录链接、各送审场景记录链接
GitHub 仓库：母项目编码-客户名称-期号，仓库链接
场景开发目录：对应场景文件夹链接
送审版本：commit
第一部分｜开发架构（A+B）：该 commit 下的统一阅读入口
  A：业务流程、整体架构图及 graph
  B：九份 spec Markdown
第二部分｜开发计划：该 commit 下的独立文件链接
  计划摘要：开发时间、开发方式、预计 token 与费用范围
请求审核：需要确认的具体事项
本次变更／未决事项：……
项目经理：姓名
```
