# C4 调研、方案、技术与启动准备

[返回项目管理手册](../../project-management-handbook.md#messages) · [全部模板与参考](../README.md)

客户群消息用于推进项目。说明今天的结果，将下一步工作与所需客户支持对应起来；写清请谁、何时、做什么及对下一节点的影响，无新增配合如实注明。内部阻塞由PM协调内部支持。

```text
［日期］项目进展｜问题核实／方案设计／技术准备／启动准备
今日结果：本环节完成的具体内容，以及客户可访问的材料链接。
已确认与待确认：哪些内容已核对，哪些还需谁确认或补充。
下一步：接下来形成什么结果、进入哪个节点、已约定的时间。
需配合：请谁在何时提供或确认什么，对下一步有什么影响。
下次反馈：时间及跟进人。
```

PM按实际环节填入：

| 环节 | “今日结果”和“需配合”的重点 |
|---|---|
| 调研、问题核实 | 取得的业务事实、baseline及测法；缺少的样本、访谈对象和核对事项 |
| 定义产品、方案设计 | 当前提出或修订的目标、产品价值，以及客户怎样进入产品、完成任务并获得结果；需要客户核对的使用情境、操作和信息需求 |
| 技术准备、开发审核 | 技术准备和审核的实际状态；需要落实的数据、权限、人员和现场条件 |
| 启动准备 | 已通过的方案与实施安排；启动会时间、参与者及待签文件准备情况 |

服务日下班前发送客户简报，17:30为检查提醒；按客户可见的实际结果填写。
