# 客户可见项目事项表

[返回项目管理手册](../../project-management-handbook.md#locations) · [全部模板与参考](../README.md)

来源：已有项目群管理规范 V1.1 的八个字段。使用本项目独立事项表，客户只读；此处提供字段和空行，具体平台操作沿现有安排。

| 事项名称 | 事项编号（自动编号） | 类别 | 缺口跟进人 | 约定完成日期 | 下次反馈时间 | 状态 | 最新进展与结果依据 |
|---|---|---|---|---|---|---|---|
| | | | | | | | |

类别：执行事项、关键节点、问题、新需求。

状态：待评估、待处理、进行中、待客户、待验收、已完成、已关闭。

约定完成日期尚未确认时留空；未结束事项保留下次反馈时间。最新进展写当前情况、下一步及文档或确认记录链接。

原规范的日常客户群简报：

```text
［日期］项目进展
已完成：［事项编号与结果］
待协作或阻碍：［事项编号、谁需做什么、何时反馈］
下一步与关键节点：［重点工作、日期及变化］
```

分阶段消息见本目录 I1、C1—C7。
