# C6 试运行与验收

[返回项目管理手册](../../project-management-handbook.md#messages) · [全部模板与参考](../README.md)

按当天节点使用相应写法。

客户群消息用于推进项目。说明今天的结果，将下一步工作与所需客户支持对应起来；写清请谁、何时、做什么及对下一节点的影响，无新增配合如实注明。内部阻塞由PM协调内部支持。

```text
［日期］项目进展｜试运行
今日使用与结果：参与人员、场景、实际使用情况。
问题处理：发现的问题、处理人及反馈时间。
下一步与配合：明日验证安排，需要谁参与或提供什么。
```

```text
［日期］项目进展｜验收
验收依据：启动会签字文件、受验范围及技术版本链接。
验收状态：逐项结果、遗留问题、最终验收文件及客户签字状态。
下一步与配合：整改、复验或交接安排，需要谁在何时确认。
```
