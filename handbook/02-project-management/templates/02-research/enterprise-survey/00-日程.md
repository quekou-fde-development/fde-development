|  |  | (一)企业总体调研:一号位访谈、组织架构 |  |  |
|  |  | (二)仓库:负责人访谈 → 标准流程走查 |  |  |
|  |  | 错误流程复现、各环节负责人 ‖ 工位测量、硬件条件 |  |  |
|  |  | 质量体系负责人访谈 ‖ WMS 接口字段 + 隧道方案 |  |  |
|  |  | 指标汇总、资料清点;仓库提前结束则(四)财务提前 |  |  |
|  |  | 复盘、能力证明样本处理、次日补问清单 |  |  |
|  |  | (三)客服:负责人 → 坐席(电话)→ 线上样本 → 工单与质检 ‖ 知识底稿评估 → 自动应答体验 |  |  |

|  |  | 调研汇报会议:一期范围共识 |  |  |
