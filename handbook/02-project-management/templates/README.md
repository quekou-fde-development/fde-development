# 项目管理模板与参考目录

[返回项目管理手册](../project-management-handbook.md#materials) · [项目管理入口](../README.md)

复制空白模板后填入本项目事实。填写后的文件存到知识库「FDE全链」对应项目；技术文件按开发手册在项目私有仓库维护，并关联知识库。消息格式直接用于本项目群或项目记录。

这里收录现有格式及从已提供原件抽出的脱敏栏目。调研表单保留原有问题与表格，完整现场手册和项目专属策略从知识库读取。文档Skill只有已发布的Meta Spec有入口，其余留空。
