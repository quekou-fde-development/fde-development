# spec 写作参照

本目录提供九种技术规格的写作参照。**按项目需要编写，不要求每个项目一次写齐九份，也不进入送审包。** 需要编写时，FDE 在架构审核通过后，依据冻结版架构设计和同版业务材料起草；缺少业务规则、权限或信息去向时先回补架构设计。

[Meta Spec 工具](../../tools/meta-spec/README.md)可辅助生成候选规格，但不能替代架构审核、内容复核和实际测试。开发计划使用[正本](../开发计划.md)。
