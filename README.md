## 本周改动

- 2026-11-11：按角色重排为五个目录，取消 `handbook` 层；流程扩为九节点，新增⑤方案与⑨维护。
- 送审统一为开发计划、架构设计（含架构图）、解决方案三件，范围与报价作为附件；spec 改为按项目需要编写。
- 调研报告拆为对内、对外两份；对内版合并原通用调研输入结构与 11.09 骨架。
- 流程图原件的节点、说明与校验哈希同步更新，登记见 [MAINTENANCE](MAINTENANCE.md)。

具体项目的填写版存知识库「FDE 全链」对应项目。修改共用规范时提交 Pull Request，说明变化、依据及验证结果；本轮结构重排只保留在本地，验收通过前不推送。
