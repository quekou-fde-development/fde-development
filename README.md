# 缺口 FDE 开发规范

开发手册、配套工具和反馈入口集中维护于本仓库。

| 入口 | 用途 |
|---|---|
| [流程与开发手册](handbook/) | 先读 FDE 总流程，再读技术开发细则；调研输入与九份 spec 参照按任务使用 |
| [开发工具](tools/) | 按具体工具归拢的说明、源码、ZIP、使用条件与官方入口 |
| [反馈](feedback/) | 填写反馈、查看进度、追踪修改和验证结果 |

当前提供 10.08 手册、调研空表、现成工具包与反馈入口。各工具的版本和使用条件见 [工具清单](tools/catalog.json)。项目架构仍按手册提交总架构师审核。

每个真实交付项目按[技术手册 §5.1—5.2](handbook/development-handbook.md)与 Arcubase 母项目关联，在本组织按系统项目编号建立唯一仓库，仓库名固定，客户项目默认设为 private。项目经理先 push 包含业务流程与 spec 的开发文档和独立开发计划，再通过邮件异步送审；获批后在原仓库持续维护实现和测试产物。客户资料与凭据保留在获授权的项目范围内。

Arcubase 维护母项目、子项目（场景）、核心项目内容及实际推进记录。GitHub 按场景编号组织开发目录，保存正式开发文档、代码、技术变更、测试与发布版本，并链接对应 Arcubase 记录。

修改共用规范时提交 Pull Request，说明变化、依据及验证结果。架构与正式方法变更由总架构师审核；开发计划模板随手册提供。
