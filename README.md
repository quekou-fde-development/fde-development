# 缺口 FDE 开发规范

开发手册、配套工具和反馈入口集中维护于本仓库。

| 入口 | 用途 |
|---|---|
| [开发手册](handbook/) | 从架构设计、总架构师审核到开发、验证和发布的步骤与产出 |
| [开发工具](tools/) | 实际工具包、配套文件、版本、使用条件与官方入口 |
| [反馈](feedback/) | 填写反馈、查看进度、追踪修改和验证结果 |

当前已发布 10.06.4 手册、调研空表、现成工具包与反馈入口。各工具的版本和使用条件见 [工具清单](tools/catalog.json)。项目架构仍按手册提交总架构师审核。

未来每个真实交付项目独立建立仓库，默认设为 private，保存该项目的架构九文档、开发计划、实现和测试产物。客户资料与凭据保留在获授权的项目范围内。

修改共用规范时提交 Pull Request，说明变化、依据及验证结果。架构与正式方法变更由总架构师审核；开发计划标准化后补。
