## 链接怎么打开

镜像保留知识库原始字节，文内链接随原文保留：

- 指向镜像内部文件的相对链接可在仓库直接打开。
- `/kb/<路径>` 在平台知识库同路径打开；可先进入[知识库交付入口](https://fde.autostaff.cn/team/team_6811f9f5-205b-4b6b-bef4-870eecb44651/preview?sourceKind=kb&logicalPath=%2Fkb%2FFDE%E6%96%B9%E6%B3%95%E8%AE%BA%E4%B8%8E%E4%BA%A7%E5%93%81%2F01_FDE%E4%BA%A4%E4%BB%98%2F00_overview.md)。
- `fde.autostaff.cn/...preview?...logicalPath=/kb/…` 预览地址直接打开，需要相应团队权限。
- 项目管理工作手册中的延期回复函使用跨区相对路径，目标只在知识库归档；请通过[延期回复函预览](https://fde.autostaff.cn/team/team_6811f9f5-205b-4b6b-bef4-870eecb44651/preview?sourceKind=kb&logicalPath=%2Fkb%2FFDE%E6%96%B9%E6%B3%95%E8%AE%BA%E4%B8%8E%E4%BA%A7%E5%93%81%2F99_%E5%BD%92%E6%A1%A3%2F2026-11-19_%E4%BA%A4%E4%BB%98%E8%A7%84%E8%8C%83%2F%E5%8E%86%E5%8F%B2%E6%A8%A1%E6%9D%BF%2F%E5%BB%B6%E6%9C%9F%E5%9B%9E%E5%A4%8D%E5%87%BD.md)打开。
