# 缺口 FDE 手册与工具

[handbook](handbook/) 按总流程与三个岗位手册分为四块。进入各块后，再查看正文及配套资料。

| 四大块 | 入口 |
|---|---|
| 1. 总流程 | [FDE 总流程](handbook/01-workflow/) |
| 2. 项目管理手册（项目经理） | [项目管理手册](handbook/02-project-management/) |
| 3. 架构设计手册（架构师） | [架构设计手册](handbook/03-architecture/) |
| 4. FDE开发手册（FDE） | [FDE开发手册](handbook/04-development/) |

共用工具在 [tools](tools/) 按工具名维护，手册内连接对应说明、源码和下载包；问题提交及处理见 [feedback](feedback/)。

尚未具备的模板与文档 Skill 在对应手册内留空。具体项目的文件在知识库「FDE全链」对应项目查阅；开发版本与技术记录按 FDE开发手册在对应项目仓库维护。工具版本和验证范围见[工具清单](tools/catalog.json)。

修改共用规范时提交 Pull Request，说明变化、依据及验证结果，经夏洛克审核后更新发布。项目方案与开发正式送审采用PM组织的邮件；手册、模板和工具问题使用GitHub反馈入口。
