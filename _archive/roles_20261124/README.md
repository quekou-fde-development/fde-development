# FDE 八阶段交付流程

每段以本段方法论和产出模板形成结果，再交给下一段。三次需求在第 3 段现场调研中逐项对齐；架构审核为第 4 段内闸；试运行、交接与回款在第 7 段处理，未结事项由第 8 段接续。

| 阶段 | 输入 | 产出 | 方法与模板 |
|---|---|---|---|
| 1 商机背景 | 客户线索与商务交接信息 | 客户资料清单 | [阶段入口](2-项目经理/项目管理工作手册.md#stage-1) |
| 2 商务建联 | 客户资料清单 | 二次需求 ＋ 客户版调研手册 ＋ 确认的调研安排 | [阶段入口](2-项目经理/项目管理工作手册.md#stage-2) |
| 3 现场调研 | 二次需求 ＋ 客户版调研手册 ＋ 确认的调研安排 | 调研报告 ＋ 妙记链接 | [阶段入口](2-项目经理/项目管理工作手册.md#stage-3) |
| 4 架构方案 | 调研报告 ＋ 妙记链接 | 架构（开发方案）、产品方案、开发计划 | [阶段入口](2-项目经理/项目管理工作手册.md#stage-4) |
| 5 项目启动会 | 架构（开发方案）、产品方案、开发计划 | 需求清单 | [阶段入口](2-项目经理/项目管理工作手册.md#stage-5) |
| 6 开发测试 | 需求清单 | 产品 | [阶段入口](2-项目经理/项目管理工作手册.md#stage-6) |
| 7 项目验收 | 产品 | 验收单 | [阶段入口](2-项目经理/项目管理工作手册.md#stage-7) |
| 8 售后维护 | 验收单 | 维护记录 | [阶段入口](2-项目经理/项目管理工作手册.md#stage-8) |
