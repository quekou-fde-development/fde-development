# 架构师

| 文件 | 用途 |
|---|---|
| [架构手册](架构手册.md) | 每个项目填一份；填好即架构设计，包含架构图及送审核对项。 |
| [架构方法论](架构方法论.md) | 六段判断、依据与报价的方法。 |
| [架构理论](架构理论.md) | 架构判断的理论依据。 |
| [对外架构图](对外架构图.md) | 从架构手册取材，形成 1–2 页客户可读图。 |
| [解决方案](解决方案.md) | 从架构手册摘出的客户可读方案，PM 核对范围与验收口径。 |
| [demo说明](demo说明.md) | 方案确定后由 FDE 制作 demo 的说明空壳。 |

方案阶段由架构师主做架构设计、对外架构图和解决方案；PM 主做开发计划、范围与报价，架构师分别辅助排期和提供成本依据。送审只交开发计划、架构设计（含架构图）、解决方案，报价作附件。
